# 备考文档资料

本目录收录经过文件内容哈希去重和公开安全初筛的备考文档。视频、安装包、实操数据集、构建产物和重复副本不在此目录中。

当前版本包含 493 份文档（254.19 MB），排除 77 份需复核文档，并去除 1,213 个重复副本。

## 目录

```text
files/
├─ guangdong/    # 广东、广州、珠海、佛山相关
├─ shanghai/     # 上海地区
├─ shenzhen/     # 深圳地区
└─ national/     # 国标或无明确地区
```

每个地区下再按三级、四级、五级或混合等级，以及理论、实操、考试信息、工具和其他内容分类。`catalog.json` 记录文件的 SHA-256、大小、类别和已去除的重复副本数。

## 筛选规则

- 仅收录 PDF、Word、Excel、PowerPoint 和纯文本文档。
- 使用 SHA-256 按实际内容去重，不按文件名判断。
- 排除 50 MB 及以上文件，避免接近 GitHub 单文件限制。
- 排除文件名或路径标注“请勿外传”、“水印”、“机构流出”、“独家”等限制的内容。
- 排除命中邮箱、手机号、身份证号或 API 密钥格式的 OOXML/文本文件。
- 排除作者元数据中直接包含邮箱或手机号的 PDF。

筛选只是自动化初检，不代表已获得内容授权，也不能替代人工隐私审查。旧版 `.doc`/`.xls` 是二进制格式，未进行正文自动扫描，上传前必须人工检查。原始 Office 文档的作者元数据未被改写。

## 重新生成

在 Windows PowerShell 7 中从项目根目录运行：

```powershell
pwsh -File scripts/prepare-materials.ps1
```

未纳入的文档和原因会写入本地 `.codex_qc/github-materials-audit.csv`，该文件不会提交到 Git。
